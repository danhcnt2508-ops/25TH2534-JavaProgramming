# 25TH2534-JavaProgramming

\# Java Programming Exercises



Kho lưu trữ này chứa danh sách các bài tập thực hành và bài tập về nhà thuộc môn học \*\*Lập trình Java\*\* (`25TH2534-JavaProgramming`). Dự án được phân chia thành các cấu trúc bài học rõ ràng tương ứng với lộ trình học tập.



\## 🛠️ Yêu cầu hệ thống \& Môi trường

\* \*\*Ngôn ngữ:\*\* Java

\* \*\*Môi trường chạy (JRE):\*\* JavaSE-21 \& JavaSE-17

\* \*\*Công cụ phát triển (IDE):\*\* Eclipse / IntelliJ IDEA

\## 📂 Cấu trúc mã nguồn



\### 1. `Bai1Hello` (Sử dụng JavaSE-21)

Thư mục chứa các mã nguồn làm quen bước đầu với ngôn ngữ lập trình Java, cấu trúc điều khiển và các phép toán cơ bản.

\* \*\*Package:\*\* `ntu`

&#x20; \* `HelloWWorld.java`: Chương trình xuất dòng chữ chào mừng cơ bản (Hello World).

&#x20; \* `HinhVe.java`: Thao tác xuất ký tự vẽ các hình học cơ bản lên màn hình console.

&#x20; \* `SayHello.java`: Chương trình nhập xuất tên và gửi lời chào cá nhân hóa.

&#x20; \* `TinhToan.java`: Các phép tính toán số học căn bản (cộng, trừ, nhân, chia).



\### 2. `Bai2\_BaiTapThucHanh` (Sử dụng JavaSE-17)

Tập hợp chuỗi bài tập thực hành trên lớp nhằm củng cố tư duy thuật toán và lập trình hướng đối tượng cơ bản.

\* \*\*Package:\*\* `(default package)`

&#x20; \* `BaiTap1.java`: Bài tập thực hành số 1.

&#x20; \* `BaiTap2.java`: Bài tập thực hành số 2.

&#x20; \* `BaiTap3.java`: Bài tập thực hành số 3.

&#x20; \* `BaiTap4.java`: Bài tập thực hành số 4.



\### 3. `Bai2\_BaiTapVeNha` (Sử dụng JavaSE-17)

Các bài tập ứng dụng tự làm ở nhà giải quyết các bài toán toán học, tài chính và quản lý thực tế.

\* \*\*Package:\*\* `(default package)`

&#x20; \* `Phuongtrinhbac1.java`: Giải và biện luận phương trình bậc nhất một ẩn $ax + b = 0$.

&#x20; \* `QuyDoiTienTe.java`: Ứng dụng chuyển đổi tỷ giá giữa các đơn vị tiền tệ khác nhau.

&#x20; \* `TinhTienLuong.java`: Bài toán tính lương nhân viên dựa trên các tham số ngày công, phụ cấp và hệ số lương.

\## 🚀 Hướng dẫn cài đặt và Chạy ứng dụng



1\. \*\*Clone repository này về máy:\*\*

&#x20;  ```bash

&#x20;  git clone https://github.com

&#x20;  ```

2\. \*\*Mở dự án:\*\*

&#x20;  \* Mở IDE của bạn (Eclipse hoặc IntelliJ IDEA).

&#x20;  \* Chọn `Import Project` và trỏ tới thư mục vừa tải về.

3\. \*\*Cấu hình SDK/JRE:\*\*

&#x20;  \* Đảm bảo cấu hình đúng phiên bản JRE tương ứng (`JavaSE-21` cho Bài 1 và `JavaSE-17` cho Bài 2) trong phần thiết lập dự án (`Project Structure` / `Build Path`).

4\. \*\*Chạy file:\*\*

&#x20;  \* Nhấp chuột phải vào file `.java` bất kỳ muốn kiểm tra (ví dụ: `HelloWWorld.java`) và chọn \*\*Run As -> Java Application\*\*.
