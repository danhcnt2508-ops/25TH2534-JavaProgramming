\### 5. `Bai3.InOutData` (Sử dụng JavaSE-20)

Xử lý các thao tác nhập dữ liệu từ bàn phím và xuất dữ liệu ra màn hình, kết hợp đọc/ghi dữ liệu với tệp tin (File I/O).

\* \*\*Package:\*\* `(default package)`

&#x20; \* `FileWriter\_PrintWriter.java`: Thao tác ghi dữ liệu văn bản ra ngoài file hệ thống.

&#x20; \* `ExceptionHandling.java`: Xử lý ngoại lệ (Try-Catch) để chương trình không bị lỗi đột ngột khi nhập/xuất file.

&#x20; \* \*\*File dữ liệu đi kèm:\*\* `data.txt`, `output.txt`

\### 9. Các ví dụ về Lập trình hướng đối tượng (OOP) (Sử dụng JavaSE-17)

Chuỗi bài tập làm quen với tư duy lập trình hướng đối tượng, cách định nghĩa Class (Lớp), khởi tạo Object (Đối tượng), quản lý các thuộc tính (Attributes) và phương thức (Methods).



\* \*\*Package chung:\*\* `ntu.danhtm2534`



\#### 🔹 Project: `ViDuOOP\_HinhChuNhat`

Quản lý và tính toán thông tin hình học cơ bản sử dụng tư duy đối tượng.

\* `HinhChuNhat.java`: Định nghĩa lớp Hình Chữ Nhật với các thuộc tính chiều dài, chiều rộng và các phương thức tính chu vi, diện tích.

\* `MainHinhChuNhat.java`: Chứa hàm `main` để khởi tạo thực thể hình chữ nhật, nhập dữ liệu và xuất kết quả tính toán ra màn hình.



\#### 🔹 Project: `viDuOOP\_SinhVien`

Mô hình hóa thông tin thực thể dữ liệu trong quản lý giáo dục.

\* `SinhVien.java`: Định nghĩa cấu trúc lớp Sinh Viên (Mã số, họ tên, điểm số...) cùng các phương thức getter/setter và hiển thị thông tin.

\* `Main.java`: Lớp thực thi chương trình, quản lý luồng nhập xuất và kiểm tra dữ liệu của đối tượng sinh viên.



\#### 🔹 Project: `ViDuOOP\_XeHoi`

Mô phỏng đối tượng thực tế trong đời sống vào lập trình.

\* `XeHoi.java`: Định nghĩa lớp Xe Hơi chứa các đặc trưng (thương hiệu, màu sắc, vận tốc...) và các hành vi (khởi động, tăng tốc, hãm phanh).

\* `MainXeHoi.java`: Lớp điều khiển chính dùng để tạo mới các đối tượng xe hơi và vận hành các phương thức của chúng.

\## 🚀 Hướng dẫn cài đặt và Chạy ứng dụng



1\. \*\*Clone repository này về máy:\*\*

&#x20;  ```bash

&#x20;  git clone https://github.com

&#x20;  ```

2\. \*\*Mở dự án:\*\*

&#x20;  \* Mở IDE của bạn (Eclipse hoặc IntelliJ IDEA).

&#x20;  \* Chọn `Import Project` và trỏ tới thư mục vừa tải về.

&#x20;  \* Đảm bảo cấu hình đúng phiên bản JRE tương ứng (`JavaSE-21` cho Bài 1 và `JavaSE-17` cho Bài 2) trong phần thiết lập dự án (`Project Structure` / `Build Path`).

4\. \*\*Chạy file:\*\*

&#x20;  \* Nhấp chuột phải vào file `.java` bất kỳ muốn kiểm tra (ví dụ: `HelloWWorld.java`) và chọn \*\*Run As -> Java Application\*\*.
